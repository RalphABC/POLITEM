Patrones de diseño

Controles anti-alucinación y de datos
• Las cifras las calcula el código; el modelo solo redacta · • Cada afirmación cita [código] y se valida contra el contexto · • Filtro por cédula/ubicación antes de la búsqueda vectorial (no se mezclan custodios) · • Reintento y respaldo determinista · • Los fragmentos no llevan el nombre del custodio; con LLM en la nube se omite el nombre y se enmascara la cédula
Despliegue y calidad
• Local: Windows 10/11, Python 3.10+, ChromaDB persistente en data/index · • Sin modelos: modo plantilla + embeddings léxicos · • Con Ollama: llama3.1:8b + nomic-embed-text (≈16 GB RAM) · • 30 pruebas pytest (API, RAG, PDF, Word/Excel) · • Pendiente para producción: SSO, roles, auditoría, PostgreSQL, firma electrónica
